# 🌐 Network Manager CLI

A Python-based network device simulator that mimics the behavior of a basic router command-line interface (CLI).

## 📌 Features

- Display router version
- Show network interfaces
- Display IP address
- Show router status
- Simulate ping responses
- Interactive command-line interface

## 🛠 Technologies Used

- Python 3
- Dictionaries
- Functions
- Loops
- Object-Oriented Programming (OOP)
- Git & GitHub

## ▶️ How to Run

1. Clone the repository:

```bash
git clone <repository-url>
```

2. Navigate to the project folder:

```bash
cd Network_Manager
```

3. Run the program:

```bash
python main.py
```

## 📷 Example Commands

```text
Router> show version
Router> show interfaces
Router> show ip
Router> show status
Router> ping
Router> exit
```
